# Weather Bot Engine

Консольное приложение на Python для получения текущих метеоданных по названию города в реальном времени.

## Функционал
* **Интеграция с API:** Отправка GET-запросов к эндпоинту OpenWeatherMap.
* **Безопасность:** Изоляция API-ключей в конфигурационном файле `.env`.
* **Логирование:** Вывод в консоль даты, времени, адреса запроса и HTTP-статуса ответа.
* **Обработка ошибок:** Защита от сбоев сети (try-except) и обработка некорректного ввода (код 404).
* **Парсинг JSON:** Извлечение вложенных параметров (`temp`, `feels_like`, `description`, `speed`).

## Запуск
1. Установите зависимости:
   ```text
   pip install requests python-dotenv
   ```
2. Создайте файл `.env` в корне проекта:
   ```text
   WEATHER_API_KEY=ваш_api_ключ
   ```
3. Запустите скрипт:
   ```text
   python weather_bot.py
   ```
